# ТИХО — путешествия по России

Учебный многостраничный сайт туристических маршрутов. Откройте `index.html` в браузере или используйте любой статический сервер. Все ссылки относительные.

Страницы: главная, каталог с фильтрами, маршрут (`tour.html?tour=baikal`, `altai`, `karelia`, `kamchatka`), контакты с формой заявки. Форма демонстрационная: сервер и отправка данных не подключены, отзывы и цены приведены для примера.

В проекте применены семантический HTML, формы и валидация, CSS-переменные и состояния, Flexbox, Grid, БЭМ-подобные имена, адаптивная вёрстка, а также Bootstrap 5 через CDN (сетка и компоненты форм). Для загрузки Bootstrap и веб-шрифтов нужен интернет. Видео и фото хранятся локально.

На странице каталога встроен виджет Яндекс Карт с переключением направлений. Для его работы нужен интернет и доступ к сервисам Яндекса; подписи и ссылки на маршруты доступны отдельно от карты. Программы по дням и условия поездок приведены как примеры.
